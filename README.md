# KarVPN — релизы

Публичный склад сборок KarVPN. Здесь лежат артефакты релизов и подписанный
документ версии, по которому клиент узнаёт о новой сборке.

## Что здесь лежит

* `version.json` в корне ветки `main` — подписанный документ версии:

  ```
  https://raw.githubusercontent.com/KarVPN/karvpn-releases/main/version.json
  ```

* GitHub Releases — файлы сборок (`karvpn-<версия>.apk`), их контрольные суммы,
  копия документа версии и changelog на человеческом языке.

## Документ версии

`version.json` — конверт:

```json
{"kid": "<имя ключа>", "payload": "<base64 JSON>", "sig": "<base64 ed25519>"}
```

`payload` — JSON документа, `sig` — подпись ed25519 его сырых байтов. Поля
документа: `type`, `version`, `issued_at`, `expires_at` и `body` с `platform`,
`version`, `build`, `url`, `sha256`, `min_supported_build`, `notes` (`ru`, `en`)
и `size`. Подпись проверяется до разбора полей; версия ниже уже известной
отвергается.

## Проверка подписи

Публичный ключ (имя ключа — в поле `kid` конверта):

```
63rPGfraDBHZSGwy24b+fgVXhIBJ6AwlHVQEEMQTHqM=
```

Проверить документ тем же алгоритмом, что и клиент: base64-декодировать
`payload`, вычислить ed25519-подпись сырых байтов и сверить с `sig` ключом выше.

## Правила

* теги и файлы релизов не перезаписываются: выпущенный документ уже обещал
  конкретную контрольную сумму;
* исправление выходит новым релизом с большей версией;
* changelog публичен и не содержит внутренних деталей.
